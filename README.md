# BlogApp

Uma aplicação web de publicação e gestão de conteúdos, desenvolvida durante os meus estudos de Node.js

---

## Sobre o projeto

O **BlogApp** é uma aplicação web de gestão e publicação de conteúdos, desenvolvida com **Node.js, Express e MongoDB**.

O projeto permite organizar publicações por categorias, gerir conteúdos através de uma área administrativa e implementar autenticação de utilizadores com controlo de permissões.

## Funcionalidades

- Publicação e visualização de artigos;
- Organização de publicações por categorias;
- Autenticação e gestão de sessões;
- Controlo de acesso para administradores;
- Gestão de mensagens de feedback;
- Interface dinâmica com Handlebars.

## Tecnologias utilizadas

| Tecnologia         | Finalidade                                |
| :----------------- | :---------------------------------------- |
| Node.js            | Ambiente de execução JavaScript           |
| Express.js         | Framework backend                         |
| MongoDB            | Base de dados NoSQL                       |
| Mongoose           | Modelação e interação com a base de dados |
| Passport.js        | Autenticação de utilizadores              |
| Express-Session    | Gestão de sessões                         |
| Connect-Flash      | Mensagens temporárias                     |
| Express-Handlebars | Motor de templates                        |

## Objetivo

Consolidar conhecimentos de desenvolvimento backend, arquitetura de aplicações web, integração com bases de dados, autenticação e gestão de utilizadores, através da construção de uma aplicação funcional e evolutiva.
